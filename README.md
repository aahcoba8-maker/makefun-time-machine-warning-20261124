## The label

> WARNING: Do not warn your past self. He ignored you the first time.

67 characters. A genuine safety notice with the paradox built in: warning your
past self is the one warning guaranteed not to work, because the person you are
warning is the same person who ignored it the first time.

## How it runs

`main.py` (Python 3, standard library only) writes the label to
`entry.txt` in `MAKEFUN_OUTPUT_DIR` when set, otherwise next to the script,
then verifies the written file matches the label exactly.

```
python3 main.py
```
